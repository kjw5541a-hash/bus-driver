# 교차로 모서리와 차량 모델 설계

작성일: 2026-09-27
범위: `road-fixes` 이후 플레이 피드백 3건. `road-fixes` 브랜치 위에서 한다.

## 배경

1. 사거리 한가운데나 모서리에 도로 면이 비어 바닥이 보인다.
2. 사거리 모서리에서 인도가 네모로 끊긴다. 도로를 따라 곡선으로 이어져야 한다.
3. 교통 차량이 색칠한 박스다. 받은 차량 모델
   (`~/Downloads/angular-apocalypse-abandoned-compact-car-intact-parked.glb`)을 쓴다.

조사 결과 원인:

1. `mesh.build_roads` 는 way 구간마다 사각형 리본을 깔고, way **중간** 꺾임점에만
   축 정렬 사각형 패치를 붙인다. 교차로는 대개 way 의 끝점이라 패치가 없다.
   두 갈래가 비스듬히 만나면 리본 모서리 사이에 쐐기꼴 틈이 남는다.
2. `mesh.build_sidewalks` 는 공유 노드(교차점)마다 앞뒤 `반폭 + 3 m` 를 잘라
   비운다. 모서리가 네모로 끊기고, 두 way 가 그냥 이어지는 노드(교차로가 아닌
   way 분할점)에서도 인도가 끊긴다.
3. 차량 모델: 메쉬 1개, 삼각형 5.8k, jpeg 텍스처 1장. 크기 1.6 x 0.78 x 0.9 m
   로 장난감 크기이고 긴 축이 X 다. 지금 차체 박스는 1.8 x 1.4 x 4.6 m 다.

## 목표와 비목표

**목표**

- 공유 노드에서 만나는 갈래 사이에 도로 면 틈이 없다.
- 인도가 교차로 모서리를 원호로 돌아 이웃 갈래 인도와 이어진다.
- way 가 그냥 이어지는 노드에서 인도가 끊기지 않는다.
- 교통 차량이 받은 모델로 보이고, 차마다 색이 다르며 경찰차는 구별된다.

**비목표**

- 공유 노드가 없는 교차(고가·지하차도) 처리. 지금처럼 겹쳐 깐다.
- 분리 차도 교차로를 하나의 큰 교차로로 합치는 것. 노드마다 따로 모깎기한다.
  가까운 노드끼리 호가 겹치면 겹친 채로 둔다(도로 면은 겹쳐도 보이는 문제가
  없고, 인도는 `_clear_runs` 가 다른 차도 위를 비운다).
- 교차로 안 차선 도색 정리. 도색은 그대로다.
- 차량 충돌면 변경. 박스 그대로 두고 겉모습만 바꾼다.
- 차종 여러 개. 모델 하나를 색만 바꿔 쓴다.

## 설계

### 1. 교차로 갈래 모으기 (bake, `mesh.py`)

`_junctions(ways, projector) -> dict[node_id, list[Arm]]`

- 둘 이상 way 가 공유하는 노드마다, 그 노드에서 뻗는 갈래를 모은다. 노드가
  way 중간이면 앞뒤 두 갈래, 끝이면 한 갈래다.
- 갈래 = `(way 인덱스, 방향 단위벡터, 반폭, 갈래 폴리라인 길이)`.
  - 방향은 노드에서 갈래를 따라 `min(10 m, 갈래 길이)` 간 점을 향한다. OSM 첫
    구간이 1 m 도 안 되는 경우가 있어 첫 구간 방향은 믿지 않는다.
  - 반폭은 `road_width(tags) / 2`.
- 방위각 순(반시계)으로 정렬한다.

### 2. 모서리 원호

정렬된 갈래에서 이웃한 두 갈래 A, B(A 다음이 B, 반시계)마다:

- A 의 B 쪽 가장자리 선과 B 의 A 쪽 가장자리 선이 이루는 모서리를 반경
  `CORNER_RADIUS_M`(6 m) 원호로 모깎기한다.
- 두 갈래 사이 각 θ 에 대해 모서리 꼭짓점에서 접점까지 거리는 `R / tan(θ/2)`.
  각 갈래의 접점 거리(노드에서 갈래를 따라 잰 값) `t_A`, `t_B` 를 기록한다.
- 반경을 줄이는 경우:
  - θ 가 170° 이상이면(거의 일직선) 호 없이 두 가장자리를 곧게 잇는다.
  - 접점 거리가 갈래 길이의 절반을 넘으면 넘지 않도록 반경을 줄인다.
  - 반폭이 서로 다른 갈래도 같은 식이다. 가장자리 선이 반폭만큼 평행이동한
    선이기 때문이다.
- 갈래가 하나뿐인 노드(다른 way 가 여기서 끝나지만 방향이 겹치는 경우 등)는
  호를 만들지 않는다.
- 호는 `CORNER_SEGMENTS`(6) 조각의 폴리라인으로 낸다.

### 3. 도로 면

- 교차로마다 노드 중심에서 호 점들을 잇는 부채꼴(팬) 삼각형으로 채운다. 호
  사이(각 갈래 입구)는 그 갈래의 좌우 접점을 잇는 직선이 경계다.
- 높이는 기존 패치와 같은 `PATCH_Y`(0.01). 리본과 겹치는 곳은 그대로 겹친다.
- 기존 중간 꺾임점 사각형 패치는 그대로 둔다(교차점이 아닌 꺾임점용).

### 4. 인도

- `build_sidewalks` 의 교차점 네모 자르기(`INTERSECTION_CLEAR_M`)를 없앤다.
  대신 교차점에서 각 갈래 인도를 그 쪽 접점 거리에서 끊는다. 갈래의 왼쪽과
  오른쪽 접점 거리가 다를 수 있으므로 좌우를 따로 자른다.
- 호를 따라 곡선 인도를 깐다. 기존 `_sidewalk_side` 와 같은 단면이다: 차도 끝
  (y 0), 연석 경사 0.25 m, 인도 윗면 2 m. 호의 조각마다 사각형을 붙이고, 조각
  경계의 법선은 호 중심에서 바깥으로 향하는 방향이다.
- 곡선 인도 조각도 `_clear_runs` 와 같은 검사로, 인도 중심점이 다른 도로
  리본 위에 있으면 뺀다.
- 인도가 없는 좁은 도로(`SIDEWALK_MIN_ROAD_WIDTH` 미만)가 낀 모서리는 호 인도를
  깔지 않는다. 도로 면 원호는 깐다.

### 5. 차량 모델 (게임)

- 모델을 `assets/models/car.glb` 로 복사하고 import 산출물을 같이 커밋한다.
- `traffic.gd` `_make_car` 가 `BoxMesh` 대신 이 씬을 인스턴스한다.
  - 크기는 모델 긴 축 길이를 `BODY_SIZE.z`(4.6 m)에 맞춘 배율로 균일하게
    키운다(약 2.9 배).
  - 긴 축이 X 라 Y 축으로 90° 돌린다. 앞뒤는 캡처로 확인해 부호를 정한다.
  - 색은 텍스처 머티리얼을 복제해 `albedo_color` 에 기존 `BODY_COLORS` 를 곱한다.
    경찰차는 `POLICE_COLOR` 를 곱하고 경광등 박스를 지금처럼 올린다.
  - 복제 머티리얼은 색마다 하나를 만들어 공유한다.
- 충돌 박스는 그대로다.

## 위험

- 분리 차도처럼 가까운 공유 노드가 몰린 곳은 호와 곡선 인도가 서로 겹치거나
  찌그러질 수 있다. 인도는 다른 차도 위를 비우므로 턱이 생기지는 않는다.
  캡처에서 보기 싫으면 노드 간 거리가 반폭보다 가까운 곳의 호 인도를 빼는
  규칙을 더한다.
- 호 인도가 연석 경사면을 갖기 때문에, 버스가 모서리를 크게 돌지 못하면 호를
  밟는다. 자율주행 검증이 교착하던 거리보다 더 짧아지면 반경을 줄인다.
- 차량 모델 텍스처가 "버려진 차" 느낌이다. 색을 곱해도 녹슨 질감이 남는다.
  보기 싫으면 텍스처를 빼고 단색으로 칠하는 쪽을 검토한다.
